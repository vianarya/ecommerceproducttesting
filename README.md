# E-Commerce Product Testing

This project contains automated tests for an e-commerce product management system using Python, pytest, factory_boy, faker, and behave (BDD).

## Project Structure
- `tests/factories.py` - Factory classes for generating fake product data
- `tests/test_models.py` - Unit tests for product models
- `tests/test_routes.py` - Unit tests for product routes
- `features/products.feature` - BDD feature scenarios
- `features/steps/` - Step definitions for BDD tests
- `service/routes.py` - Product route functions
